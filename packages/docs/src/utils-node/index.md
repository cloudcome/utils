# @cloudcome/utils-node

Node.js 端工具库，提供 Base64、加密、JSONL 等功能。

## 安装

```bash
npm install @cloudcome/utils-node
```

## 模块列表

| 模块 | 导入路径 | 功能 |
| --- | --- | --- |
| base64 | `@cloudcome/utils-node/base64` | Base64 编解码 |
| crypto | `@cloudcome/utils-node/crypto` | 加密工具 |
| jsonl | `@cloudcome/utils-node/jsonl` | JSONL 读写 |

## 版本号

```typescript
import { VERSION } from '@cloudcome/utils-node'

console.log(VERSION) // 输出版本号
```
